About This Project

Project Overview

AI-Based Crop Disease Prediction and Recommendation System Using Machine Learning and Computer Vision

This project detects crop diseases from leaf images using a MobileNetV2-based deep learning model. Users can upload images, view predictions with confidence scores, read disease information, and receive preventive recommendations.

Dataset mode: This setup uses the PlantVillage 100-Image Tomato subset (20 images each for 5 classes) for demonstration/training practice. A larger dataset is required for reliable real-world performance.

Objectives
  • Develop an AI-powered system for early crop disease detection
  • Provide disease classification using deep learning
  • Offer preventive recommendations and guidance
  • Create a user-friendly web interface
  • Maintain prediction history and analytics
Technologies Used
Frontend:
  • HTML5, CSS3
  • JavaScript
  • Bootstrap 5
  • Chart.js
Backend:
  • Python, Flask
  • SQLite
Machine Learning:
  • TensorFlow/Keras
  • MobileNetV2 Transfer Learning
  • OpenCV, NumPy, Pandas
Supported Classes (100-Image Tomato Subset)
  • Tomato — Bacterial Spot
  • Tomato — Early Blight
  • Tomato — Late Blight
  • Tomato — Leaf Mold
  • Tomato — Healthy

The architecture supports expansion to more crops and classes when a larger dataset and retrained model are provided.

Important Disclaimer

This system is developed as an academic project for MSc IT and is intended for educational purposes. The 100-image subset is a small demonstration set and is not sufficient for reliable real-world diagnosis. It should not replace professional agricultural advice. Always consult qualified agricultural specialists for critical decisions.
